# 称号バナー

| t05 | 5 | 見習いアタッカー | コモン |
| t10 | 10 | ブロッカー泣かせ | アンコモン |
| t15 | 15 | 計算高い策士 | アンコモン |
| t20 | 20 | ライフを削る者 | レア |
| t30 | 30 | 盤面の支配者 | レア |
| t50 | 50 | サキヨミの魔女 | 神話レア |
| t100 | 100 | 殴り算マスター | 神話レア |

称号名・条件・フレーバーテキストは `src/template4.html` の `TITLES` で変更できます。
