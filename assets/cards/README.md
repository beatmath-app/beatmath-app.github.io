# 称号カードのイラスト

ここに `<id>.webp`（縦長 2:3、600×900px 程度）を置くと、アプリのカードにイラストが表示されます。無いカードは「イラスト準備中」になります。

| id | 必要な連続正解（むずかしい） | 称号 | レアリティ |
|---|---|---|---|
| t03 | 3 | 初陣 | コモン |
| t05 | 5 | 見習いアタッカー | コモン |
| t10 | 10 | ブロッカー泣かせ | アンコモン |
| t15 | 15 | 計算高い策士 | アンコモン |
| t20 | 20 | ライフを削る者 | レア |
| t30 | 30 | 盤面の支配者 | レア |
| t50 | 50 | サキヨミの魔女 | 神話レア |
| t100 | 100 | 殴り算マスター | 神話レア |

称号名・条件・フレーバーテキストは `src/template4.html` の `TITLES` で変更できます。
